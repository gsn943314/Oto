# Installation

See [Install and use](README.md#install-and-use) for the current installation, API-key, and permission steps. See [Build from source](README.md#build-from-source) if you prefer building the app yourself.

macOS 11 or later is required. Choose arm64 for Apple Silicon or x64 for Intel. Each user must enter their own OpenAI API key and have available API quota. This repository contains the macOS app only.
