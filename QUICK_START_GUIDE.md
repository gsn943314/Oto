# Quick start

1. [Download the app](https://github.com/gsn943314/voice-input-assistant/releases/latest) and move it into Applications.
2. Open Settings, add your own OpenAI API key, and save.
3. Allow Microphone and Accessibility permissions.
4. Select a Trigger key, focus a text field in another app, tap the key, speak, and tap again.

See [README.md](README.md) for details, source builds, privacy, and troubleshooting. There is no separate Shortcut configuration.
